# GS-AUH | ابدأ من هنا

**منصة محاضرات طبية عربية** على GitHub Pages مع لوحة مدير خاصة تستعمل Supabase لرفع ملفات HTML أو PDF، وتعديل بطاقات المحاضرات، وإخفائها أو نشرها.

## أهم الملفات

- `START_HERE_AR.md` — دليل التثبيت الكامل بالعربية خطوة بخطوة، **ابدأ به**.
- `SUPABASE_SETUP_AR.md` — دليل إعداد Supabase المختصر مع التنبيهات الأمنية.
- `medatlas-supabase.sql` — ملف إعداد الجداول، الصلاحيات، وحاوية التخزين.
- `assets/supabase-config.js` — **يحتاج تعديلك** لوضع رابط مشروع Supabase ومفتاحه العام.
- `index.html` — الصفحة العامة.
- `admin/index.html` — لوحة المدير، دون زر ظاهر في الصفحة العامة.
- `lecture.html` — عارض محاضرات PDF وHTML.
- `lectures/ruq-pain/` — أول محاضرة، ويظل محتواها قيد المراجعة العلمية.

## المتطلبات

1. حساب GitHub ومستودع `medical-atlas`.
2. حساب Supabase ومشروع جديد.
3. حساب مدير يتم إنشاؤه داخل Supabase وإسناد صلاحياته من SQL Editor.
4. متصفح حديث واتصال بالإنترنت؛ لا تحتاج Node أو خادم خاص.

## التشغيل سريعاً

اقرأ `START_HERE_AR.md`. باختصار:
1. أنشئ Supabase ونفّذ `medatlas-supabase.sql`.
2. أنشئ حساب مدير من Authentication → Users، وأضف UUID إلى `medatlas_admins`.
3. عدّل `assets/supabase-config.js` بالمفتاح **Publishable** وProject URL.
4. ارفع **محتويات ZIP بعد فك الضغط** إلى جذر مستودع GitHub.
5. Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.
6. افتح `/admin/`، وسجّل دخولك، وارفع أول HTML أو PDF.

## حدود وتحذيرات

- بدون Supabase ستظهر المكتبة المحلية التجريبية، **لكن لوحة المدير لن تعمل**.
- الحاوية العامة تعني أن رابط الملف المباشر قابل للفتح إذا عُرف، حتى إن كانت البطاقة غير منشورة. لا ترفع بيانات مرضى أو ملفات سرية.
- ملفات HTML تعرض في iframe معزول، لذا قد لا تعمل Service Workers أو localStorage أو الميزات التي تعتمد على أصل مشترك.
- الرفع يتم بالطريقة القياسية؛ الملفات الأكبر من 6 MB قد تحتاج إلى شبكة مستقرة، ولأفضل اعتمادية يلزم تطوير رفع قابل للاستئناف (TUS).
- لم نربط هذه النسخة بحساب Supabase الحقيقي؛ اختبارات الواجهة تمت بمحاكاة تجريبية. اتبع اختبار النشر الوارد في الدليل.
- لا تحتوي الحزمة على أسماء ملفات أو مجلدات تبدأ بنقطة، احتراماً لتفضيلك.
